# `src/domain/chess/` — chess rules

**Belongs here:** `IChessEngine` and its chess.js implementation. Legal move generation, make/undo, check, checkmate, stalemate, draw detection, promotion, castling, en passant. Plain data types for squares, pieces and moves.

**Does not belong here:** anything about _where_ a square is in 3D (that is `board/`), or _which_ real-world place a piece is named after (that is `theme/`).

**Built in:** Phase 2.
