# `src/mapdata/elevation/` — ground shape

**Spike passed (D-022):** Terrarium tiles on AWS Open Data serve 256² RGB PNGs with `Access-Control-Allow-Origin: *`, no key, worldwide. Verified for coast, hills, Highlands and Alps before anything here was written.

| File                            | Responsibility                                                                                |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| `IElevationProvider.ts`         | Seam: `getHeightField(area) → { field, source, tileCount, zoom }`.                            |
| `TileMath.ts`                   | Web Mercator tile arithmetic, zoom-for-resolution, tile ranges. Pure.                         |
| `terrarium.ts`                  | RGB → metres (`R·256 + G + B/256 − 32768`). Pure, tested.                                     |
| `assembleHeightField.ts`        | Tile mosaic → board-aligned `HeightField` (handles rotation + Mercator). Pure.                |
| `TerrariumElevationProvider.ts` | Browser provider: cache → fetch → PNG decode → assemble. 4 in flight, per-tile timeout/retry. |
| `heightFieldFixture.ts`         | HeightField ↔ compact JSON (Int16 decimetres, base64).                                        |
| `fixtureAreas.ts`               | The three offline areas (flat coastal / river valley / hilly) and lazy loaders.               |
| `FixtureElevationProvider.ts`   | Serves fixtures offline, delegates other areas to the real provider.                          |
| `ElevationLoader.ts`            | Glue: area chosen → provider → view, with cancellation. Defines `IElevationView`.             |
| `fixtures/*.json`               | Generated by `npm run make-fixtures`. Do not edit by hand.                                    |

**A failed tile reads as sea level** and is logged, rather than failing the board. **A failed request** is shown in the debug panel with its reason.
