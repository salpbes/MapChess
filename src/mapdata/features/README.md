# `src/mapdata/features/` — rivers, coast, forests, peaks, names

| File                         | Responsibility                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `IFeatureProvider.ts`        | Seam: `getFeatures(area) → { features, source, elapsedMs }`.                               |
| `overpassQuery.ts`           | The one Overpass QL query per area (D-024).                                                |
| `normalizeOverpass.ts`       | Raw Overpass JSON → `MapFeature[]` in board metres. **The only file that reads raw JSON.** |
| `OverpassFeatureProvider.ts` | Network path: cache → 2 s rate limiter → primary/fallback endpoint → normalise → cache.    |
| `FixtureFeatureProvider.ts`  | Serves the three fixture areas offline; delegates everything else.                         |
| `summarizeFeatures.ts`       | Counts by kind + named list with old/historic flags; text report.                          |
| `FeatureLoader.ts`           | Glue: area chosen → provider → view + console report, with cancellation.                   |
| `fixtures/*.json`            | Raw Overpass responses (slimmed). Generated by `npm run make-fixtures:features`.           |

**Rules:**

- Raw Overpass JSON never leaves this folder. Fixtures are raw on purpose so the normaliser is what the tests exercise.
- Overpass is a free community service. Every request goes through the `RateLimiter` and the IndexedDB cache; the public instance returns 406 to generic user agents and 429/504 when busy — the provider fails over, the generator backs off.
- Deciding what a feature _means_ for the game is `domain/theme/` (Phase 10), not here.
